# 🏠 HappyTogether – Roommate Management Platform

A full-stack web application that helps roommates **manage shared living efficiently** by centralizing expenses, chores, decisions, and group interactions.

---

## 🚀 Project Overview

Living with roommates often leads to:
- unclear expenses
- forgotten chores
- messy decision-making
- lack of coordination

**HappyTogether solves this by providing a shared digital platform** where roommates can manage everything in one place.

---

## ✨ Key Features

### 💰 Expense Management
- Track shared expenses
- Calculate balances per roommate
- Transparent group spending

### 📅 Chores & Planning
- Assign and track tasks
- Calendar-based scheduling
- Completion tracking

### 🗳️ Group Decisions
- Create polls
- Vote in real-time
- Shared decision-making system

### 🎭 Social Interaction Layer
- “Drama Tracker” leaderboard system
- Community interaction scoring

### 🔐 Authentication
- Secure login & registration
- Cookie-based sessions
- Password encryption (bcrypt)

## 🏗 Architecture

1. User logs in / registers
2. Joins or creates an apartment group
3. Interacts with:
   - expenses
   - chores
   - decisions
4. Backend handles:
   - authentication
   - database logic
   - group synchronization
5. Frontend updates UI dynamically

---

## 🗄️ Data Model (simplified)

- Users (roommates)
- Apartments (groups)
- Expenses
- Chores
- Decisions (voting system)
- Leaderboard (social scoring)
